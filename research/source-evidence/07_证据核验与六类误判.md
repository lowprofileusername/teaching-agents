# 07 · 证据核验与六类常见误判

> 来源：2026-10-25 对 17 场专家视频做全量核验，以及 2026-10-27 对 36 场做第二轮静音、空档、幻觉、实体与双模型交叉复核时暴露的误判模式。
> 适用：任何"从视频/PPT 里取证据写材料"的工作。**这些错误写进申报书会被评委当场问穿。**

---

## 一、三种"没有"必须分清（最容易搞混）

| 说法 | 可能真相 | 正确表述 |
|---|---|---|
| "没有数字" | 可能**有数据但没做成图表**，或数据在别的页 | "未见量化图表" ≠ "没有数据" |
| "没有成效数据" | 可能**有数字但不是成效**（如 AI 解题正确率、动画演示数值） | 要区分"过程数据 / 工具性能数据 / 成效数据" |
| "快闪没讲" | 可能**平台里有、只是口头跳过了** | "口头未展开" ≠ "没有" |

> 实证：于歆杰有 8 个百分比，全在 P09/P10，是 **AI 解题正确率**（5/15/30/25/25%、3/3/53%），**不是教学效果**。
> 所以说"整场无数字"是错的，说"无教学成效数据"才对。
> 又：潘守东 12 个百分比里，40/45/39/42% 是"蛇咬自救"动画的救治成功率——**动画数据不是成效数据**。

---

## 二、10 秒快筛法（先做这个，能挡住 3/4 的误判）

在判"某场没有量化证据"之前，**先跑一次全文百分比检索**：

```bash
grep -oE "[0-9]+(\.[0-9]+)?%" 报告.md | sort | uniq -c | sort -rn
# 或 Python
python -c "import re,sys;t=open(sys.argv[1],encoding='utf-8').read();print(len(re.findall(r'\d+(?:\.\d+)?%',t)))" 报告.md
```

判读：
- 命中 **0** → 只能说明“未发现百分比”，继续查人数、件数、分数、达成度、完成率等其他数字；全部核实后才能判断证据类型，**不能仅凭百分比为 0 宣布“零量化”**
- 命中 **>0** → 逐个看这些数字**属于哪一类**（成效 / 过程 / 工具性能 / 动画），再下结论

> 2026-10-25 实测：22 条否定性结论里 **4 条误判，其中 3 条能被这一步挡住**。

## 三、六类常见误判（每类都有实证）

### ① "零证据"类结论写反
| 场次 | 原结论 | 实际 |
|---|---|---|
| 曹敏惠 | 零学生作品／零课堂照片／零问卷 | P15 有 4 张课堂实景照，P19 有 30+ 张照片墙 + 问卷二维码 |
| 金海京 | 成效证据为零 | P16 完成率 85%／掌握率 70%，P19 91.23%/83.77%，P38 72.87% |
| 刘学莘_新工科 | 成效无量化、证据薄弱 | **漏收整页 P28**：发明专利 1 件、实用新型 4 件、北大核心 + CSCD 各 1 篇 |
| 宋晓菲 | 未展示问卷原文或数据明细 | P30 是整页学情图表：学习动力环形图 + 知识基础雷达图 + 用人单位"现状 vs 期望"柱状图 |
| 俞梅芳 | 全程没有任何学生端证据 | P15 手机端公开评图，列出 4 名学生姓名 + 总分 + 评语 |

→ 修正方向都是同一句话：**把"没做"改成"做了但没讲成叙事"**。

### ② 虚标"已目检"（诚信级问题，最危险）
把 `![frame](f_xxx.jpg)` 的文件名抄进报告，标成"已目检"，但**从未真的打开那张图**。
- 危害：**不标他会自己核，虚标他会直接信。**
- 处置：三档 —— 真看过→保留 `（已目检 f_xxxxxx.jpg@mm:ss 确认）`；没看过→补看；看不了→降级 `（据 md 页段记录，未目检）`
- 机器查不出来。实测三种自动判据全部失败（误报率 22%→65%→样本过小）。
  **唯一可靠办法：强制留痕 + 随机抽查。**

### ③ 假精度（臆造的数字）
症状：精确到小数点后两位，却在画面上**找不到任何对应**。
- 实证：俞梅芳报告里的 `30分→18.0 / 13.38 / 8.38 / 6.56 / 5.82`——投影和 OCR 均不可辨，**疑为上一轮分析臆造**。
- 可替用的真实数据：学生总分 72.10/71.40/66.60/65.33、"专家评价占 60%"、维度分值 30/20/10/20/10。
- 处置：整体降级 `【待核实】`，写明"不得引用，如需使用请回看原视频人工核读"。

### ④ 把"页面文字"当"专家口头原话"
- 实证：金海京"不会评价，就无法真正读懂学生"、张静"一棵树摇动另一棵树"、刘学莘"学生要 V.S. 教师给"——**全是 PPT 上印的字**。
- 答辩时说成"某教授说过"，会被当场打回。引用时写明"页面原文"或"口述"。

### ⑤ 把"AI 智能体的话"当专家原话
- 实证：唐丹 P14 那两句"我不能直接替您定锚点哦…""你们打算用真实的判例…"，是她的**智能体在跟学生对话**，不是唐丹本人说的。
- 处置：标"智能体原话（教学情境演示）"。

### ⑥ 引述他人当本人观点
- 实证：叶齐引**潘懋元**、张静引**雅斯贝尔斯**——必须写"引用"，不能写"说"。

## 四、同一份报告内的自相矛盾（提交前必扫）

实测出现的例子：
- 俞梅芳：L324 已承认"唯一数字是 4 名学生总分"，但 L65/L172 仍写"没有任何学生端证据／无数据"
- 刘战合：同一份 PPT 里"270 余套"（P18–P20）与"200 余套"（P25）并存
- 张静："六步"与"七步"自相矛盾（画面实为 7 个方框）

**自检方法**：把同一事实的所有出现处抓出来并排比对
```
人数 / 套数 / 页数 / 学时 / 百分比 / 年份
```
用户自己的 PPT 也要扫——评委翻页时会发现前后不一。

## 五、核查清单（引用任何一条证据前，逐项打勾）

- [ ] 这句话是**口述**还是**页面文字**？来源标清了吗？
- [ ] 是不是**智能体/AI 的话**？是不是**引述他人**？
- [ ] 时间戳在哪？能定位到秒吗？
- [ ] `f_xxxxxx.jpg` 我**真的打开看过**吗？还是只抄了文件名？
- [ ] 这个数字是**成效数据**、**过程数据**、还是**工具性能/动画数据**？
- [ ] 精确到小数点后两位的数字，画面上**真的有**吗？
- [ ] 同一份材料里，这个事实有没有**另一种说法**？

## 五之二、证据分级：口述撑不起强主张（非常重要）

核验时会遇到一个陷阱：**转写里确实有这句话，但幻灯片上什么都没有**。这时不能因为"他说了"就当成"已被证明"。

| 等级 | 画面 | 口述 | 判定 | 用法 |
|---|---|---|---|---|
| **一级** | 有 | 有 | 可核证据 | 可放心引用 |
| **二级** | 有 | 无 | 可核证据（页面证据） | 可引用，注明"页面文字" |
| **三级** | **无** | **有** | **仅"讲者自述"** | **不可当证据**，尤其对强主张 |
| 四级 | 无 | 无 | 无 | 不可用 |

**关键判例**：
- 某场口述"学生**自造**了一个 AI 虚拟农户智能体"，但幻灯片只有"联合师生共建"六个字 → **这条不能写成"学生自造智能体"**。口述支撑不住这么强的主张，只能写"讲者称学生参与共建"。
- 某场口述"未来核心竞争力包含'对世界的善意'"，但幻灯片四宫格只有四项、无此项 → 标【讲者自述，页面无】。
- 某场口述"六个价值转换"、"三个转变"三句，幻灯片零命中 → 同上。

**为什么这条比"有没有原话"更重要**：
评委核对的是**材料**。你写"学生自造了智能体"，评委翻到那一页只看到"共建"两个字，就会认为你夸大。**口述是弱证据，页面才是硬证据。**

**报告里的写法**：
```
【已核实·转写 mm:ss】"原话" —— 但幻灯片无对应表述【讲者自述】
```
不要因为"转写里确实有"就把【待核实】改成"已证明"。

## 五之三、数字基准争端的仲裁协议（制度性解法，比"更谨慎"可靠）

**背景**：2026-10-25 一夜之间，"讲者人数"这个基准被改了三次（9 位 → 3 位 → 9 位），每次都有充分理由，每次都在破坏已落盘的内容。根因不是谁不谨慎，而是**没有仲裁规则**。

### 协议（三条，简单到可以立刻执行）

1. **谁的更正，谁举证。**
   提出数字更正的一方，**必须附带画面原文**（OCR 片段或帧图文件名 + 时间戳）。
   **贴不出原文 = 不构成更正**，原结论保持不变。

2. **证据强度排序：画面原文 > 报告记载 > 口头汇报 > 他人转述。**
   当两方证据强度相同时，**保留原结论，标注分歧**，不强行统一。
   典型：A 说"名单页 9 人"、B 说"名单页 3 人"——若 A 能贴出含 9 个姓名的 OCR 页，B 只是转述，则 A 胜；若两者各有画面，说明**指向的是不同页/不同单元**，应并列写明，而不是判谁对。

3. **同一基准在一轮内最多更正一次。**
   第二次要改，必须由**主控者**（项目负责人）先贴证据再发指令。
   > 这条是给自己上的锁：主控者最容易凭"刚听到的一句话"就发全局更正，
   > 而一次错误的全局更正，破坏力远大于十次局部错误。

### 常见成因（避免下次重演）
| 成因 | 表现 | 防法 |
|---|---|---|
| **跨单元混用** | 把 A 单元的名单页人数套到 B 单元 | 更正前先问"这是哪一场的画面" |
| **把转述当证据** | "某代理说名单页是 3 位" | 要原文，不要转述 |
| **样本取窄** | 看了 3 场就宣布全局规律（如"代表帧是页首帧"） | 全量复算，或明确写"仅据 N 场" |
| **带边界的批量替换** | 替换"4 场"把"P53–P54 场域贯通"改成"P53–P5…域贯通" | 先 dry-run、用精确串、替换后验伤 |

## 五之四、转写同音字：ASR 文本**绝不能直接复制成引文**

小模型（base/small）对**专有名词、术语、叠词**的同音误听率很高。**即使时间戳完全对得上，文字也可能错。**

### 实测错例（2026-10-25）
| 实际说法 | 转写产出 |
|---|---|
| 本地化部署 | 本地**画**部署 |
| 金箍棒（比喻） | 金**筋骨**棒 |
| 订单制学生 | **静淡制**学生 |
| 真题真做 | **真体**真做 |
| AN / AI | AN（转写疑为 AI） |
| 设计案例库 | 设计**安妮**库 |
| 试航 | 试行 |
| 刘战合 | 刘**湛**和 |
| 慧小柒 | 慧小**七** |

### 规则
1. **引文必须"画面 OCR × 转写"交叉**：术语、机构名、平台名，以**幻灯片上的字**为准；幻灯片没有的，标 `（转写疑为…，待听）`。
2. **不要把转写文字当"原话"直接写进申报书**。写"据转写，其表述为…（专有名词待核）"。
3. 平台名尤其危险：某场的平台名报告里全篇写错（**EnzyMind 被写成 InMind**，5 处），就是靠"口述发音 → 转写 → 报告"一路传下来的。
4. 数字也同理：「三百年」「300 余项」这类，必须看画面。

## 七、36 场第二轮复核新增纪律（2026-10-27）

### 1. “没有转写”先证明“没有声音”

- 对尾部和内部空档测静音比，不凭时长缺口直接判漏转。
- 刘学莘尾部约 388 秒中 99.4% 为静音，不是漏转；陆国栋末段是音频轨源边界，不是音画错位。
- 长空档不能只看 `max_volume`，一次爆音就会抬高；应看空档内静音比例并实转核查。

### 2. 双模型用于找疑点，不用于宣布真相

- 我方 small 与另一套 large-v3 独立转写重叠比对，低相似区间只列为候选问题。
- 8 处共 161.7 秒确属漏转，是因为重转写与独立模型语义吻合；不是简单以“另一个模型不同”为据。
- 陈后金场两个模型都出现乱码，说明**一致不等于正确**；该场仍只能引画面文字。

### 3. 幻觉必须整句与循环识别，不能只扫关键词

- 马建青段 102 出现“请不吝点赞、订阅、转发……”的套话幻觉，与课程无关。
- “志愿者、频道、转发”等词在正常教学中也可出现，关键词法会误伤；应结合整句模板、连续重复和语义语境判定。
- 幻觉只标不删，从引用和页语音拼接中剔除，保留原始识别供审计。

### 4. 原始识别与修正值并存

- `segments.text` 永保识别原文；修正只写 `text_fixed`，漏转写入独立补录表并标 `[补]`。
- 实体更正采用页面证据和词级替换；对方标“须听核、不能默改、需语境”的一律不直接采纳。
- 批量替换设长度守卫并抽查，防止把整句误压成一个词。

### 5. 机器完成不等于复核通过

任何引用前仍需确认：时间轴是否闭合、帧是否真实打开看过、实体是否与画面一致、数字是否有分母、该场是否允许引口述。
