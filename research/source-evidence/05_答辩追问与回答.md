# 答辩追问与回答骨架

> **铁律**：所有回答必须基于**真实材料**。不得替用户编造教学经历、数据或成果。
> 没有的就说"尚未做，计划是……"——诚实扣分远小于被戳穿。

---

## 一、评委最可能追问的 12 类问题

| # | 问题 | 回答的核心要件 | 常见失分 |
|---|---|---|---|
| 1 | **你为什么要这样改革？** | 一个**已被论证为必要的高阶目标** + 目标与旧培养模式的**时代性差距** | 只说"学生基础差"（这不构成痛点） |
| 2 | **创新在哪里？** | 一句话说清，且与"别人怎么做"形成**对比** | 罗列工具/平台（那是标配） |
| 3 | **AI 为什么必要？不用行不行？** | 说明**没有 AI 就做不到**的那个具体环节 | "AI 提高效率"这种泛泛之词 |
| 4 | **你的多个智能体，凭什么算多个？** | 说明**功能互斥**（按工序分工，不是按任务分） | 答不上来 → 创新被降级为工具堆 |
| 5 | **教学改革具体怎么实施的？** | 环节 + 学生行为 + 产出，**每步对应学生成长路径的分解** | 只讲教师做了什么 |
| 6 | **你怎么证明教学有效？** | 前后测 + 复测口径 + 第三方证据 + 个体故事 | 只有过程截图/满意度 |
| 7 | **数据是怎么来的？样本多少？** | **口径明确**：何时测、多少人、题型是否可比 | 说不清 n 的来源 |
| 8 | **学生用 AI 抄作业怎么办？** | 结构性解法（分类治理），而非禁止 | "我们禁止学生用 AI" |
| 9 | **AI 给出错误答案怎么办？** | 错误是**教学资源**：怎么让学生发现、核验、担责 | 说"我会审核"（那是教师在判断，不是学生） |
| 10 | **创新能否持续？换个人还能做吗？** | 沉淀物（平台/资源/制度）+ 推广证据 | 只依赖教师个人投入 |
| 11 | **哪些做法可以推广？** | 明确**可复制的部分**与**依赖本地条件的部分** | 声称全部可推广 |
| 12 | **有什么局限？** | **主动说真局限**（这是加分项） | 回避或敷衍 |

## 二、可直接引用的专家观点（回答时引为佐证）

**关于"AI 为什么必要/教师价值"**
- 「AI 能提供答案，教师培养**学生对答案负责的能力**」——辛页（新医科一等奖）05:00–05:24
- 「技术的终点不应是**替代人**，而是**成就人**」——辛页 00:46
- 「AI 是催化剂不是产物……**方向与平衡仍由人决定**」——曹敏惠（课程思政一等奖）06:20
- 「用 AI 就像照镜子，**你强它就强，你弱它就弱**」——汪琼 11:29–11:46
- 「AI 的模型不会背锅……**最后总需要有人去背锅**」——于歆杰 19:29

**关于"什么样的学生是好学生"**
- 「AI 时代最好的学生不是一做就对的学生，而是**会做错、能发现错、能找到原因、能改错**（哪怕 78%）的学生」——汪琼 22:24–22:57
- 与刘学莘「只解决问题=二等奖，**解决+生成问题=一等奖**」32:04–33:43 **互证**

**关于"作业归属/学术诚信"**
- 摄影类比：「人在驱动相机，相机没有做工作」→ 学生思维驱动 AI 的作品可以是他的作业；「**没有统一一刀切的标准，判定权在教师**」——汪琼 23:00–24:21
- 分类治理：基本题禁 AI / 协作题评判断过程 / 延伸题放开——于歆杰 23:51–26:11

**关于"证据"**
- 刘学莘：「你说你增加前沿了。**有没有证据？有没有截图？**」
- 刘学莘统计的一等奖选手中**多有校级青教赛经历，但也存在无青教赛经历的科研反哺型**——有相关经历可自然提及，没有则强调长期教改实绩，不编造履历

**关于"赛道公平性"**（若被质疑学校平台/历史荣誉不足）
- 人工智能赛道：一流课程命中率 **33.33%**、教学成果奖命中率 **33.33%**，且**一等奖团队中特等奖零重合**
- 刘学莘结论：「**非大佬直通，中青年团队凭借教改实绩同样可突围**」

## 三、回答骨架（按问题类型）

### 类型 A：为什么改革（问题 1）
```
1. 先说目标升级：行业/技术已经变了 → 国家对这门课提出了新要求
2. 再说旧培养够不上：按旧目标培养的学生做不到什么（举真实事例）
3. 最后说差距不可逆：这不是"学生差"，是"时代变了"
```
❌ 避免："学生基础薄弱、学习积极性不高"（这是无效痛点）

### 类型 B：创新在哪里（问题 2、4）
```
1. 一句话主张（反常识优先）
2. 对比：别人怎么做 → 我怎么做 → 差别在哪
3. 最小可验证单元：一个具体环节的前后变化
```
示例骨架（旅游电商）：「多数 AI 课在讲 AI 多好用，我这门课在讲 **AI 必须被规矩拦住**。」

### 类型 C：怎么证明有效（问题 6、7）
```
1. 基线数据（何时测、多少人、什么题）
2. 干预过程
3. 复测（同一批人/同类变式题/间隔多久）
4. 第三方佐证（企业/行业/竞赛）
5. 一个学生的具体转变（含原话）
```
⚠️ 每一步的**口径都要能说清**。说不清 n 从哪来 = 数据作废。

### 类型 D：局限（问题 12）
```
主动给 2-3 条真实局限 + 每条对应改进计划
```
这是**加分项**。宋晓菲、于歆杰（"我刚才说的是一张我们正在吃的饼……措施是否有效，我不是特别有把握" 28:53–29:45）、刘学莘都展现了诚实姿态，且都被认可。

## 四、绝对不能做的事

1. ❌ **编造成效数据、前后测、问卷、样本量、提升百分比**——一问就穿帮
2. ❌ **把计划中的工作说成已完成**——"我们做了 X"必须是真做了
3. ❌ **把专家的案例说成自己的**——引用时明确说"借鉴了 XX 的做法并改造为…"
4. ❌ **声称全部可推广**——评委知道资源依赖
5. ❌ **过度彩排导致答辩像背稿**——刘学莘明确说真实的突发比完美表演更好（29:50–30:36）
6. ❌ **回避"这个数据怎么来的"**——必须能答

## 五、答辩前的最后自检

- [ ] 能否用**一句话**说出你的创新？（3 秒内能说完）
- [ ] 能否说出**评委预期是什么、你哪里超出预期**？
- [ ] 每个数据能否说清**何时、多少人、怎么测**？
- [ ] 有没有**一个可回溯的匿名学生编号、真实原话或作品**可以讲？（公开材料不出现学生姓名）
- [ ] 有没有**第三方**的一句话可以引用？
- [ ] 主动准备了**几条真实局限**？
- [ ] 两节课的教学视频里，有没有体现**区域/国家需求**的那一处？
