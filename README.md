# 教学资料智能体 · 静态形象版

三个独立启动版本：李静形象、原创女教师、原创男教师。三者共用用户指定的36场讲座 SQLite 资料库，形象不决定检索范围。回答由用户配置的 API 生成，不代表任何真人发言。

## Windows 使用

1. 下载一个对应形象的 Windows amd64 EXE，双击启动。程序会在本机随机端口提供界面并打开默认浏览器；保留程序窗口，关闭窗口即停止服务。
2. 程序尝试自动定位 EXE 上三级目录、Z 盘和 SMB 共享中的资料库。未找到时，在“API / 资料库设置”填写现有 `expert_videos_v1.sqlite3` 的完整路径。
3. 当前用户路径为 `Z:\第五届高校智慧教育与教学创新成果交流会\codex_analysis_tmp\qa\compact_database\expert_videos_v1.sqlite3`。也可设置环境变量 `TEACHING_LIBRARY_DB` 或使用已挂载共享盘的其他盘符。
4. 不配置 API 也能浏览36场目录、检索页面、放大截图、查官方课件、回听库内音频。对话需填写兼容 Chat Completions 的 HTTP 或 HTTPS Base URL、模型名称及 API Key；无认证的本地服务可以不填密钥。例如 Unsloth 使用 `http://127.0.0.1:8888/v1`，不是网页地址 `/chat`。另一台电脑的服务请使用该电脑的局域网 IP，127.0.0.1 始终指运行 EXE 的电脑。
5. 三种角色均有系统音色朗读。李静版本可选填写已授权 ElevenLabs 音色 ID，或在确认针对李静本人授权后提供本地声音样本申请音色；这不是已经完成的声音克隆，也不能跳过服务方身份验证。

## 数据与证据

- 数据库在共享盘上只读打开，截图、音频块、官方PDF直接从库内读取，不在EXE中重复打包1.784GB的资料库。
- 当前源库：36场、1568检索单元、60803条多版本转写、617音频块、10份官方课件383页。此数字是数据库条数，不是已完成整场听校的证明。
- R编号为视频展示/检索单元，圆桌场为主题；原PPT页码单独显示，未知则保留未知。
- 关键词检索区分页面、自动转写、原始OCR、官方PDF与研究判断；比较题保留不同专家来源。它不是完整课程教案或全库语义理解的保证。
- 请求原话时可查多版本转写；搜索“快闪”或“OCR”时补查原始OCR。未整场原声听校的记录仍带限制，不能把原声入口当成已听过。
- 原片中的页码/标签差异、转写疑项与核查问题不会因为接入智能体而被清零。

## 安全及存储

本地服务只监听127.0.0.1，API使用随机会话令牌并校验来源。支持多组 API 配置保存、切换、删除和模型列表连接测试。名称、Base URL、模型和随机凭据引用写入 EXE 旁的 `teaching-agent-profiles.json`（可用 `TEACHING_AGENT_PROFILES` 指定路径）；程序目录须可写。对话密钥保存到 Windows 凭据管理器或 macOS 钥匙串，不写入明文 JSON。三个角色放在同目录时共享配置，重启自动恢复上次选中配置。换电脑必须重新输入密钥；系统凭据存储属于系统管理的小量本地数据。声音服务设置仍仅保留本次进程。HTTP 不加密，请用于可信的本机或局域网服务，公网服务建议 HTTPS。提问及本次检索证据会发送到你填写的API服务。图库、讲座数据库、原声与密钥未提交到仓库；Release只含程序、AI静态形象和说明。浏览器自身缓存由浏览器管理。

## 当前范围

当前是静态图片，不会旋转、眨眼或对口型；男女原创首版为原生1024×1536，未声称4K。没有真人代言，也未完成付费声音服务的真实调用验收。真实36场数据库在macOS做只读集成验证；GitHub Actions在Windows用合成数据库运行测试及EXE启动检索验收，不会上传用户库。

## 构建

Go 1.27.4。Windows：`CGO_ENABLED=0 go build -ldflags "-X main.defaultPersona=male" .`，persona可选 `lijing`、`original`、`male`。macOS使用CGO SQLite驱动，Windows使用纯Go SQLite驱动，规避macOS SMB上的驱动系统调用缺口。

发布 `v*` 标签后，GitHub Actions运行Windows测试、构建三个EXE、启动检索验收，全部通过才创建Release。未设置真实数据库的CI会跳过私有源库集成测试。
