# 教学资料智能体 · 静态形象版

三个独立启动版本：李静形象、原创女教师、原创男教师。三者共用用户指定的36场讲座 SQLite 资料库，形象不决定检索范围。回答由用户配置的 API 生成，不代表任何真人发言。

## Windows 使用

1. 下载一个对应形象的 Windows amd64 EXE，双击启动。程序会在本机随机端口提供界面并打开默认浏览器；保留程序窗口，关闭窗口即停止服务。
2. 程序尝试自动定位 EXE 上三级目录、Z 盘和 SMB 共享中的资料库。未找到时，在“API / 资料库设置”填写现有 `expert_videos_v1.sqlite3` 的完整路径。
3. 当前用户路径为 `Z:\第五届高校智慧教育与教学创新成果交流会\codex_analysis_tmp\qa\compact_database\expert_videos_v1.sqlite3`。也可设置环境变量 `TEACHING_LIBRARY_DB` 或使用已挂载共享盘的其他盘符。
4. 不配置 API 也能浏览36场目录、检索页面、放大截图、查官方课件、回听库内音频。对话需填写兼容 Chat Completions 的 HTTP 或 HTTPS Base URL、模型名称及 API Key；无认证的本地服务可以不填密钥。例如 Unsloth 使用 `http://127.0.0.1:8888/v1`，不是网页地址 `/chat`。另一台电脑的服务请使用该电脑的局域网 IP，127.0.0.1 始终指运行 EXE 的电脑。
5. 三种角色均有系统音色朗读。李静版本可选填写已授权 ElevenLabs 音色 ID，或在确认针对李静本人授权后提供本地声音样本申请音色；这不是已经完成的声音克隆，也不能跳过服务方身份验证。

## 数据与证据

- 数据库在共享盘上只读打开，截图、音频块、官方PDF直接从库内读取，不在EXE中重复打包约2.70GB的资料库。
- 当前源库：36场、1568检索单元、60803条多版本转写、617音频块、10份官方课件383页。此数字是数据库条数，不是已完成整场听校的证明。
- R编号为视频展示/检索单元，圆桌场为主题；原PPT页码单独显示，未知则保留未知。
- 关键词检索区分页面、自动转写、原始OCR、官方PDF与研究判断；比较题保留不同专家来源。它不是完整课程教案或全库语义理解的保证。
- 请求原话时可查多版本转写；搜索“快闪”或“OCR”时补查原始OCR。未整场原声听校的记录仍带限制，不能把原声入口当成已听过。
- 原片中的页码/标签差异、转写疑项与核查问题不会因为接入智能体而被清零。

## 安全及存储

本地服务只监听127.0.0.1，API使用随机会话令牌并校验来源。支持多组 API 配置保存、切换、删除和模型列表连接测试。名称、Base URL、模型和随机凭据引用写入 EXE 旁的 `teaching-agent-profiles.json`（可用 `TEACHING_AGENT_PROFILES` 指定路径）；程序目录须可写。对话密钥保存到 Windows 凭据管理器或 macOS 钥匙串，不写入明文 JSON。三个角色放在同目录时共享配置，重启自动恢复上次选中配置。换电脑必须重新输入密钥；系统凭据存储属于系统管理的小量本地数据。声音服务设置仍仅保留本次进程。HTTP 不加密，请用于可信的本机或局域网服务，公网服务建议 HTTPS。提问及本次检索证据会发送到你填写的API服务。图库、讲座数据库、原声与密钥未提交到仓库；Release只含程序、AI静态形象和说明。浏览器自身缓存由浏览器管理。

## 当前范围

当前是静态图片，不会旋转、眨眼或对口型；男女原创首版为原生1024×1536，未声称4K。没有真人代言，也未完成付费声音服务的真实调用验收。真实36场数据库在macOS做只读集成验证；GitHub Actions在Windows用合成数据库运行测试及EXE启动检索验收，不会上传用户库。

## 构建

Go 1.27.4。Windows：`CGO_ENABLED=0 go build -ldflags "-X main.defaultPersona=male" .`，persona可选 `lijing`、`original`、`male`。macOS使用CGO SQLite驱动，Windows使用纯Go SQLite驱动，规避macOS SMB上的驱动系统调用缺口。

发布 `v*` 标签后，GitHub Actions运行Windows测试、构建三个EXE、启动检索验收，全部通过才创建Release。未设置真实数据库的CI会跳过私有源库集成测试。


## v0.3.0：报告、材料审阅与思考设置

- 新数据库扩展提供 PDF 逐页文字与来源检索。报告是研究判断，不能当专家原话。第七届2027国赛正式标准尚未取得；校赛和第六届文件始终显示参考状态。
- 新版数据库已嵌入66份完整研究报告/图表/规则PDF，点击来源时优先读库内原件并核对SHA256，不需要原共享盘。旧库未嵌入时仍支持原路径或数据库旁的report目录。
- 上传 PDF、DOCX、PPTX、TXT/MD 在本机内存解析，选择页/段后提问。PDF按物理页，PPTX按演示顺序，Word按段落组。仅选中单元及检索证据会发给所选模型。单文件≤50MB、PDF/PPTX≤300页。这不是整份文档自动完整审阅；逐页选择后可导出对话意见。
- 当前提取原生文字层，不做图片OCR、SmartArt/母版/备注提取或视觉版式审核，扫描页会显示没有文字。即使接入视觉模型，本版本也不会自动把页图发给它。
- 每个 API 可保存思考开关、接口参数格式、推理等级、上下文窗口、最大输出。Unsloth 选择 enable_thinking；DeepSeek选择 thinking.type；支持推理等级的代理可选择 reasoning_effort。可用档位由真实服务决定，不能根据截图中的勾选认定兼容。
- 服务默认模式不主动发送思考开关。开启思考可能增加延迟和费用；本地32.8k窗口可填32768、输出8192；只有服务确实支持才填更大的上下文。采用保守字符预算，不是精确token计数，截断会标注。
- 状态栏区分数据库检索与等待模型，显示已等待秒数；可取消请求。浏览器等待本机检索最长45秒（服务查询上限30秒）、模型等待最长10分钟。取消浏览器请求不保证远端已停止计费。

## Apple Silicon / M4 Mac

下载 macos-arm64.zip 后解压，双击 `.app`。适用于M系列芯片（包括M4），macOS15及以上。应用启动本机服务并在默认浏览器打开界面，数据库仍从SMB只读访问。将 `.app` 放在可写的共享盘项目目录，API配置文件保存在 `.app` 的同级目录，三个角色可共享配置。钥匙串属于系统管理的本机凭据存储。程序仅有 ad-hoc 签名，未完成 Apple Developer ID 公证，首次打开可能需要在系统设置中确认允许打开；不要求关闭系统安全保护。

## 出差与检索性能

复制更新完成的 `expert_videos_v1.sqlite3` 到 Windows 本地后，在设置中指向该路径即可。库内截图、音频块、官方课件、报告原PDF和文字均可离线查阅；生成回答还需本地模型或可联网API。API密钥不会随数据库复制。

新版修正“根据讲座”误触发整场转写扫描的问题，截图改为点击加载，问答不读取媒体BLOB；资料库补齐page_utterance等5个索引。状态栏分别显示检索耗时和模型等待。目标是常用文字检索5秒内，实测值取决于机器、磁盘、共享盘及是否正在更新；不能承诺模型回答也在5秒内。更新EXE与数据库后重试，旧EXE不会自动获得新的检索逻辑。

## 直接可用的无损压缩库

`expert_videos_v2_portable.sqlite3`保留标准SQLite结构；检索正文和索引不压缩。仅对节省至少5%的媒体BLOB使用zlib，`media_encoding`记录编码、原始长度和SHA256。点击媒体时v0.3.0解码并核验，搜索不解压媒体。旧版EXE不支持压缩媒体，请使用v0.3.0及以上；其他智能体查询文字仍用标准SQLite，导出媒体须按media_encoding无损解码。未经验证的中间文件不得作为交付库。

程序内置100问目录，可选择后填入提问框；保存选择的数据库路径，重启后优先连接该路径。

## v0.3.1：可读的专业回答

标题、列表、加粗、表格会安全渲染；详细检索来源折叠显示。模板任务优先交付可填写的结构与示例句式，正文不堆R编号和时间；只在末尾保留精选依据。新文科等问题优先检索对应一等奖案例，不默认所有课程都必须使用AI。回答仍由所选模型生成，需要检查出处和事实，提示词不能保证任何模型都完全遵循。

## v0.3.3：证据确实送达模型

修复检索成功但上下文预算分支清空证据的问题。前端保留全部选中页面的摘录，后端按来源缩减重复元数据；显示实际发送证据数/候选证据数及上传材料状态。无法保留有效证据时不调用模型。32768上下文、4096最大输出的正常配置不必更改。实际模型输入内容已用本机模拟接口检查；这不等于真实模型答案质量认证，也未调用用户API。
