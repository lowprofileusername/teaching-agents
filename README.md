# 教学创新备赛工作台 v0.4.8

面向准备教学创新大赛的高校教师。两个启动形象：原创女教师、原创男教师；程序内可以切换。形象不限制资料库范围，AI 回答不代表任何真人专家本人。

## 安装与连接

- Windows：下载对应 `windows-amd64.exe`，双击打开原生工作台，需要 WebView2 Runtime。
- Apple Silicon / M4：下载 `macos-arm64.zip`，解压打开 `.app`，要求 macOS 15 及以上。应用是 ad-hoc 签名，尚未 Developer ID 公证；首次打开可能需要系统设置确认，不需要关闭系统安全保护。
- 两个版本均在本机启动仅监听 `127.0.0.1` 的服务。使用 `-browser` 可改为浏览器模式，`-no-browser` 用于接口测试。
- 程序目录需可写。配置与可控的运行缓存放在程序旁；也可用 `TEACHING_AGENT_PROFILES` 指定配置文件的绝对路径。在共享盘运行时，请先确认已经挂载。macOS、WebView 和系统凭据库自行管理的缓存不在此保证范围内。
- “设置与连接 → 模型与资料库”支持保存多个 HTTP/HTTPS Chat Completions 接口，填写 Base URL、模型名和密钥；无认证的本机服务可留空。Unsloth 示例为 `http://127.0.0.1:8888/v1`，不是 `/chat`。另一台电脑的模型要填它的局域网 IP。
- 密钥保存在 Windows 凭据管理器或 macOS 钥匙串，配置 JSON 仅保存随机凭据引用。换电脑需重新输入。HTTP 用于可信本机或局域网，公网建议 HTTPS。

## 七个工作区

| 工作区 | 实际功能 |
|---|---|
| 备赛概览 | 赛道/课程设置、三类材料准备情况、备赛简报、准备计划提问 |
| 创新报告 | DOCX 标题与目录识别、章节正文、逐段 AI 审阅、意见与建议替换文本；全文自动分批，可取消并继续未完成批次 |
| 课堂实录 | SRT/VTT 字幕时间轴、重叠/无效时间/长空档检查、课堂行为手动标注、选段审阅；可选本机视频并按字幕时间回放 |
| 汇报与答辩 | PPTX/PDF 页目录、逐页提取文字、讲述秒数与总时长、讲稿草稿、选页审阅和评委追问 |
| 综合核查 | 汇集三个工作区材料、选择片段对照、六项证据链记录、带出处的数字提及清单 |
| 回看讲座 | 按时间同步库内原声、截图和转写；保留上次节点，恢复后不自动播放 |
| 专家资料库 | 按专家/学校/课程筛选场次、页面目录、截图、课件、逐句转写及原声入口 |

各工作区的材料文字、问答、已完成批次、讲稿、标注和回看节点自动保存到独立工作记录库。草稿约1秒防抖保存，审阅批次完成后立即提交；请确认显示“已保存”再关闭。主窗口重启恢复最近记录，中断请求不会自动重发。通过“历史与恢复”可恢复、另存副本或导入新版导出的完整JSON。新上传的DOCX/PPTX/PDF原件按SHA256保存在配置目录的 material_sources 文件夹，用于图片读取与Word导出；不写进讲座数据库、不覆盖用户原件。原件缓存不随工作记录JSON导出，换电脑需一并携带该文件夹或重新添加原件。本机视频需重新选择。问答仍可单独导出 Markdown、TXT、JSON。

“新建空白窗口”不带材料；“在新窗口继续追问”复制近期上下文、当前任务和选中材料片段。各窗口独立对话，共用 API、数据库和教师设置。追问上下文只在本机内存短暂保存、一次读取后删除，不复制密钥。模型历史最多使用最近4轮；导出可包含窗口内完整可见问答。

## 材料审阅的范围

支持 PDF、DOCX、PPTX、TXT/MD、SRT/VTT；单文件不超过50MB，PDF/PPTX不超过300页。解析在本机进行，选中片段或分批审阅的文字连同检索证据发送给所配置模型。DOCX 以段落标识，PDF 是物理页，PPTX 按演示顺序。

本版文字审阅与图片审阅分别启动、分别计数。支持正文嵌入 PNG/JPEG/GIF 图片，以及 PDF 整页画面（含扫描页）；须勾选确认所选 API 支持图片。图片通过 image_url 输入传给兼容视觉模型，每批一张，最长边最多2048像素；不支持图片的模型返回错误时不会退成文字审阅冒充完成。Word/PPT的 SmartArt、原生图表、母版、页眉页脚和完整页面排版不在嵌入图片范围，可另存PDF进行整页审阅。原视频仍未自动听辨。视频播放不表示模型已经看过画面。批次完成表示原文对应区间已送达模型且返回有效结构，不代表真人验收或事实认证。建议替换文字显示在工作台；DOCX 可把已完成意见写为批注，或另存含插入/删除修订的 Word 副本；批注作者为“教创赛专家”。复杂图片/域/链接/已有修订段落只添加建议批注，保留正文；导出结果列明跳过项。数字提及不同不会自动判定为矛盾。

## 资料库与独立参考

支持 `expert_videos_v1.sqlite3`、可直接查询的无损媒体压缩版 `expert_videos_v2_portable.sqlite3`，Claude 的 `expert_videos.db`，以及 WorkBuddy wb1 的 `expert_videos_workbuddy.sqlite3` / `expert_videos_workbuddy_revised.sqlite3`。WorkBuddy 标记和作者质量台账会展示，不把对方的验收记录当作本轮听校。源 SQLite 始终只读；一次连接一个库。Claude 库在内存建立文本适配表，图片和音频按需读取，不自动合并两个库。

Claude 分卷先按顺序二进制合并：Mac `cat expert_videos.db.part0 expert_videos.db.part1 > expert_videos.db`；Windows CMD `copy /b expert_videos.db.part0+expert_videos.db.part1 expert_videos.db`。不要在已有完整文件上重复覆盖。

- Codex `songxiaofei:R12` 与 Claude `song:P12` 是不同编号；均不能直接当原 PPT 角标。原页码未知则保留未知。
- 页面、自动转写、官方课件、研究判断分开展示。原声入口不代表已经完成整场听校。
- 出差时可将完整数据库复制到本地并选择其路径。库内媒体可独立读取，只有旧库中未嵌入的文件仍依赖外部路径。问答还需要本地模型或联网 API。
- 问答检索不读取大媒体 BLOB；压缩库仅在打开媒体时解压和核验。常见检索目标5秒内，实际受磁盘和共享盘影响，不承诺模型也在5秒内回答。
- 不连接外部库也有第六届9赛道评分参考、27项评分材料和34位专家的公开资料目录。**这不是第七届正式规则**；内置资料始终注明届次与出处。模型不可冒称真实评委或某位专家本人。
- 页面内置100问。未配置 API 时可以直接检索资料与查看证据，不会假装生成模型建议。
- `library_query.py` 可供其他智能体直接查询。例：`python library_query.py --db expert_videos.db page song:P12`。

## 思考、流式回答和语音

每个聊天 API 可配置上下文窗口、最大输出、思考开关/参数格式和推理等级。仅在服务支持时启用；例如32768上下文、4096输出。显示接口实际返回的 reasoning 文本，不生成或推测隐藏思维。状态栏区分检索、等待接口、接收思考与接收答案，可取消请求。

“教师声音”独立于聊天 API，支持兼容 OpenAI 的语音接口、Azure Speech 和可选本地 Qwen3-TTS 包。默认在线兼容接口，不加载1.69GB本地模型。在线服务需自行配置地址/音色/密钥，服务额度由提供方决定；没有默认免费无限接口。密钥存系统凭据库，不回传到设置响应。

可选本地包需单独配置，不随 EXE 打包。支持模型实际提供的9个音色，含 Serena 和 Uncle_Fu；本地推理内存可能数GB。在线模式不会在本机加载这些权重。在线接口已做协议模拟测试，发布本身不代表用户账号的真实朗读已验收。

## 桌面教师

独立置顶透明窗口，支持行走、站立、坐下、90秒空闲自动休息和朗读期间停步。拖动方向滑块可以预览多角度形象，当前为二维序列而非可任意俯仰的三维模型。女教师使用16帧高清步行、24张多角度画面；男教师保留8帧步行与24角度序列。各角度按人物高度和基线归一化，不混合相邻画面造成重影。生成姿态仍可能有细节差异，未声称真人动作捕捉或逐字口型同步。

## 构建和发布

Go 1.27.4，Windows 使用纯 Go SQLite，macOS 使用 CGO SQLite。

```sh
# Windows
CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -tags desktop -ldflags '-X main.defaultPersona=original' .
# Mac
MACOSX_DEPLOYMENT_TARGET=15.0 CGO_CFLAGS=-mmacosx-version-min=15.0 CGO_LDFLAGS=-mmacosx-version-min=15.0 go build -tags desktop,private_mac_apis .
```

发布 `v*` 标签后，Actions 运行测试、构建两个 Windows EXE并启动检索检查；再构建两个 Apple Silicon 应用，全部成功才公开 Release。CI 使用合成数据库，用户讲座库、报告、原声、配置和密钥不随程序上传。

布局参考 MaClaw 的导航轨、任务区和工作台组织方式；代码独立实现，未复制其源码或人物素材。原生窗口使用 MIT 许可的 Wails。第三方许可见 `THIRD_PARTY_LICENSES.txt`。


### v0.4.8 操作入口

- 点击左侧教师头像查看介绍与能力。
- “材料与工作区 / AI 审阅结果”切换中央内容，“查看来源证据”打开可关闭的侧栏。
- 创新报告可先检查整体结构；全文审阅会继续逐段核对，位置建议不改动原文件。
- PPT 先选页，再问“这一页怎么样”；发送栏显示本轮页码。整份结构分析基于逐页标题，完整文字审核请使用逐页审阅。
- 回看讲座在本地库中选择讲座和时间节点，不需要聊天 API。
- 普通聊天默认不自动附带材料；可勾选当前材料，明确的本页问题自动带入所选页。
- 阅读思考文本时可停在开头，点击“查看最新回答”才恢复跟随。
- 运行中的不同工作区可以切换与并行请求；取消只影响当前任务，模型服务可能自行排队。

详细更新与边界见 RELEASE_NOTES.md。

工作恢复：工作记录存放在 API 配置文件同目录的 workbench_history.sqlite3，和只读讲座库分离；按窗口保存并检查修订号，冲突不会覆盖。通过“历史与恢复”恢复或另存副本。新建空白窗口不带旧任务，重启主窗口恢复最近记录；不会自动重发中断请求。

专业分工：预制备赛总顾问、报告论证、课堂实录、汇报答辩、评价成效、AI融合、课程思政和规则材料核查八类AI顾问。按工作区推荐，可手动选择；与真实讲座专家的有据视角独立叠加。分工是AI研究方法，不能充当当届官方评分标准。

## 图片审阅与 Word 写回

在“材料与审阅范围”中选择章节或页面，确认当前聊天 API 支持图片，再点击“审阅所选范围的图片 / PDF页面”。文字与图片意见独立计数，可取消后继续。PDF按物理页；Word图片按正文段落编号锚定，不能当作Word排版页码。图片看不清或编码不支持会保留未处理提示，模型意见不是数据真实性认证。

DOCX审阅后点击“写回 Word 批注 / 修订”，选择仅批注或批注加修订，并指定输出文件夹。所有内容另存新文件；正文原文和段落编号必须与缓存原件一致，否则拒绝写回。原有图片、表格、样式与批注保留，普通文本建议采用段落级可接受/拒绝修订；新文字继承首个文本运行的样式，复杂段落保留建议批注，不自动移位或破坏对象。源文档带宏或数字签名时拒绝写回。导出只包含已完成意见，部分审阅不等于全文验收。


## v0.4.8 界面与任务

左侧固定七个模块和各模块的历史任务；可新建、恢复，并在同一模块同时运行不同任务。中间为材料/整页审阅结果/回看播放器；来源证据按需展开。课程赛道与设置从顶栏进入，教师完整原图在介绍内可查看。导航、证据、正文高度、文档目录、讲座节点、字幕和回放提问栏可拖动，双击分隔线复位，“设置与连接”也能恢复默认布局。

回看讲座的问题绑定所选讲者和当前时间；整场转写分批完整送入模型，再合并摘要。任何批次截断或超预算都不会计为整场完成。整理库增加综合字幕视图，原转写版本仍可选择；标注“疑为”不代表实际听校。

联网默认关闭。可配置10种引擎的启用、排序、优先/错峰/汇总策略；收费引擎需自己的账户。浏览器保底使用新临时目录和独立上下文，不复用登录Cookie；开启人工验证时可打开验证页由用户完成，软件不绕过验证码。浏览器需已安装Chrome/Edge。只把查询发送给搜索服务，不自动上传完整报告。

桌面教师支持两轴移动、直接拖动、速度/大小调整和固定位置。悬停、旋转与朗读时暂停行走；试听使用所配置的语音接口，不自动替换成系统声音。当前仍是序列帧、多角度图片，并非真三维。

## 开发架构

Go + Wails 保留原生服务。`frontend/src/Shell.tsx` 为 React + TypeScript 布局组件，构建为 `web/shell.mjs`；现有问答、文档与播放器控制器以保持节点身份的接口嵌入，属于渐进迁移，尚非全应用 React 化。生产运行无需Node。

构建：在 frontend 运行 `npm ci`、`npm run build`，再运行现有 Go 构建命令；CI 两平台都会检查 TypeScript 与编译前端。详细技术选型见 `ARCHITECTURE.md`。

### 给另一位老师建立项目
顶栏选择“新老师 / 新项目”，填写教师或项目名、课程和赛道，即可开始空白备赛项目。原项目先保存至历史；API 和资料库连接继续使用。每个工作区标题旁也有“新建任务”和“重置当前任务”：前者为当前老师另开空白任务，后者先保存旧任务并取消当前请求后重置。恢复旧老师的任务时，课程信息一并恢复；综合核查只引用同一项目的材料。
