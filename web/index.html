可以帮你做什么

如何一起工作

先选择任务和赛道，添加材料，再明确提出问题或启动审阅。各任务可以独立进行；打开或关闭面板不会取消任务。

能力边界

文档文字与图片分开审阅；图片需要支持视觉的API。Word/PPT可读取正文嵌入图片，PDF支持整页画面，不能据此判断未提供的版式或原声。没有 API 时可检索资料；生成建议需要配置模型。AI 建议需由你核实，不能虚构成果或保证获奖。

工作记录与恢复

恢复材料文字、问答、讲稿和已完成批次。原始视频需重新选择；中断的模型请求不会自动重发。
